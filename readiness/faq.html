Basics

What OpenBIM is, and what this assessment does.

Short answers to the questions that come up most often, and the terms the assessment uses.

01

The basics

What is OpenBIM?

BIM is building information modelling1 — designing with a model that carries data, not just lines. OpenBIM2 is doing that using open, published file formats so the information is not locked inside one company's software.

That is the whole idea. It is not a product, a brand, or a piece of software.

Is OpenBIM something I buy?

No. It is an approach and a set of published standards. Nobody owns it and nobody sells it. You can work this way with software you already have.

What is IFC?

IFC — Industry Foundation Classes — is the main open file format for building information.3 It is published by buildingSMART,4 an international non-profit, and any software can read or write it without asking permission or paying a licence.

If you have ever been asked to “deliver in IFC”, this is what was meant.

My software already has an “export to IFC” button. Isn't that it?

That button is the starting point, not the whole of it. Almost every BIM tool has one. The question is whether what comes out is usable by anyone else — whether it carries the rooms, the classifications, the quantities and the properties that make it worth receiving.

Exports frequently open without error while carrying less than the sender assumes. That gap is what this assessment measures.

Do I have to stop using the software I have?

No. OpenBIM is about what you deliver and archive, not what you author in. Plenty of firms work openly using entirely proprietary tools.

What changes is that your information stays readable when the software, the subscription or the vendor does not.

02

About this assessment

What do I need before I start?

About fifteen minutes. Optionally one IFC file. No account, no sign-up, no API key, no payment.

What if I don't have an IFC file?

You can still take it. You receive the organisational half of the assessment, and the report states that the model half was not measured — it does not estimate, and the absence is not scored against you.

Will you see my model?

No. The file is read inside your browser and is never uploaded. There is no server to upload it to. If you choose to submit results at the end, you are shown the exact payload first, and it contains only numbers and fixed categories — no file, no names, no coordinates.

Who is funding this, and is it free to use?

It is a research instrument, developed under an academic research grant, and free to use. The platform it references as a worked example is open source. The full proposal is published at The research proposal.

The people who built it also build that open-source platform. That is why the assessment scores you against published standards rather than against any product, and why it can return “the open route is not viable for you yet”.

Am I too small for this?

No. Targets are proportionate to firm size and project type. A four-person practice is not measured against what a 200-person firm should be doing.

Is this only for BIM managers?

No. It is for anyone who delivers or receives building information — principals, project managers, contractors, owners, facilities teams. If you have ever been asked for a model, or been handed one, the questions will make sense.

What do I get at the end?

A readiness profile across five areas, a gap analysis showing where you stand against a proportionate target, an ordered set of recommendations, and — if you supplied a file — the places where your model disagreed with your answers. Downloadable as a PDF.

03

Words the assessment uses

Terms used in the assessment questions.

IFC
The open file format for building information.3 Published by buildingSMART; readable by any tool.
IFC schema version
Which edition of IFC a file uses — IFC2x3, IFC4, IFC4x3. They differ in what can be expressed, which is why contracts increasingly name one.
Property set
A named group of data attached to an element — a wall's fire rating, a door's acoustic performance. Geometry without property sets is a shape, not information.
Classification
A standard code identifying what a thing is, from a published system such as Uniclass, OmniClass or MasterFormat.5 A file-naming convention is not classification.
IfcSpace
A room or space as an object in the model, rather than as a gap between walls. Downstream uses — areas, FM, analysis — require these to exist.
CDE
Common Data Environment.6 The agreed place project information lives, with versions and status — not simply a shared drive.
EIR / AIR
Exchange and Asset Information Requirements:7 what the client says the model must contain, written down before the work starts.
Federated model
Discipline models combined for review without being merged into one file,8 so each stays owned by its author.
buildingSMART
The international non-profit that publishes IFC and certifies software for data-exchange fidelity4 — not for regulatory compliance.
ISO 19650
The international standard for managing information using BIM.9 It sets requirements; it does not define a maturity ladder.
Capability level
How reliably and repeatably your organisation does something, on the ISO/IEC 33020 scale of 0 to 5.10 It is not a grade, and it is not a compliance measure.
04

References

Every definition above traces to one of these. Standards are cited to the clause.

  1. ISO 19650-1:2018, Organization and digitization of information about buildings and civil engineering works, including building information modelling (BIM) — Information management using building information modelling — Part 1: Concepts and principles. Term 3.3.14 defines BIM as “use of a shared digital representation of a built asset to facilitate design, construction and operation processes to form a reliable basis for decisions”. ISO 19650-1 attributes the definition to ISO 29481-1:2016, 3.2, modified. ↩
  2. buildingSMART International, openBIM definition. openBIM is a vendor-neutral collaborative process permitting workflows based on neutral formats such as IFC, BCF and COBie. ↩
  3. ISO 16739-1:2024, Industry Foundation Classes (IFC) for data sharing in the construction and facility management industries — Part 1: Data schema. Current edition, superseding ISO 16739-1:2018; corresponds to IFC 4.3.2.0. ↩
  4. buildingSMART International. Publishes the IFC schema and operates the software certification programme, which verifies data-exchange fidelity against the IFC standard — not regulatory compliance. ↩
  5. ISO 12006-2:2015, Building construction — Organization of information about construction works — Part 2: Framework for classification. Note that ISO 12006-2 is a framework for developing classification systems: it does not itself provide an operational classification system or the content of the tables. Uniclass, OmniClass and MasterFormat are separately published systems built to that framework. ↩
  6. ISO 19650-1:2018, term 3.3.15: common data environment (CDE), “agreed source of information for any given project or asset, for collecting, managing and disseminating each information container through a managed process”. ↩
  7. ISO 19650-1:2018 separates these by what they relate to: 3.3.6 exchange information requirements (EIR), “information requirements in relation to an appointment”; 3.3.4 asset information requirements (AIR), “in relation to the operation of an asset”; and 3.3.5 project information requirements (PIR), “in relation to the delivery of an asset”. ↩
  8. ISO 19650-1:2018, term 3.3.11: federation, “creation of a composite information model from separate information containers”. ↩
  9. ISO 19650 series, Information management using building information modelling. Parts 1–6. Published by ISO/TC 59/SC 13. ↩
  10. ISO/IEC 33020:2019, Information technology — Process assessment — Process measurement framework for assessment of process capability. §5.2.2–§5.2.7 define capability levels 0–5 as Incomplete, Performed, Managed, Established, Predictable and Innovating. ↩

Standards texts were read from the publishers’ official preview documents; clause numbers and quoted wording are taken from those texts. Sources verified 22 August 2026.
