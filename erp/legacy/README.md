# Kernel ERP how-to topics for iDempiere (Context Help)

`local_sql/postgresql/<yyyymmddHHMM>_KernelERP_ContextHelp.sql` adds step-by-step how-to topics to iDempiere's own
Context Help (the right-hand "How To" panel). They are taken from the Kernel ERP guides,
[ERP User Guide](https://red1oon.github.io/BIMCompiler/ERPUserGuide/) and
[ERP First Setup](https://red1oon.github.io/BIMCompiler/ERP_FirstSetup/).

- **What it changes:** rows only, in iDempiere's own tables (`AD_CtxHelp`, `AD_CtxHelpMsg`, `AD_CtxHelpMsg_Trl`), and
  `AD_CtxHelp_ID` on the tabs and processes listed in the file, **only where it is empty**. No code, no table, no column.
- **What a user sees:** on those tabs the panel starts with the tab's own Name, Description and Help, read from your
  dictionary in each of your languages when the script runs, then the topic. A topic too long for the 2000-character
  message column ends with a link to the rest of it in the guide.
- **Apply:** copy the file into `<idempiere>/migration/local_sql/postgresql/` and run `RUN_SyncDB`.
  Ids come from your own sequences; every row is keyed on its UUID, so applying it again changes nothing, and a newer
  file of the same name updates the same rows.
- **PostgreSQL only** for now (no Oracle script yet).

Generated by `erp/tools/build_help_pack.js`; checked on a legacy database by `erp/tests/witness_ctxhelp_legacy.js`
(spec: BIMCompiler `prompts/VOCAB_MESSAGE_CATALOG.md` §19.17 F6).
