# Kernel ERP how-to topics for iDempiere (Context Help)

A migration script that fills iDempiere's own Context Help (the right-hand **How To** panel) with step-by-step
topics taken from the Kernel ERP user guides. Legacy's code and tables are not changed: it adds rows only.

## What it changes

- Rows only, in iDempiere's own tables (`AD_CtxHelp`, `AD_CtxHelpMsg`, `AD_CtxHelpMsg_Trl`), and `AD_CtxHelp_ID` on the
  tabs and processes listed in the script, **only where it is empty**. No code, no table, no column.
- On those tabs the panel starts with the tab's own Name, Description and Help, read from your dictionary in each of
  your languages when the script runs, then the topic. A topic too long for the 2000-character message column ends
  with a link to the rest of it in the guide. Window names in the text are bold (no in-app link: iDempiere has none
  for them); the guide links open the guide.
- Ids come from your own sequences, and every row is keyed on its UUID: applying it again changes nothing, and a
  newer release of the script updates the same rows.

## Apply

1. Copy the `.sql` file into `<idempiere>/migration/local_sql/postgresql/`.
2. Run `RUN_SyncDB`.

PostgreSQL only for now (no Oracle script yet). Checked on iDempiere 13 (13.0.0.202601182106) with `psql` running the
same SQL; not yet through `RUN_SyncDB` itself.

Generated by `erp/tools/build_help_pack.js`; never edited by hand.
