# OplogPic "design kit" film script (v7, 2026-10-14): DRAFT, nothing recorded

Showcase, not a tutorial: one poster built from a blank canvas in about 2:55, using only the features added since the v6 balloon film (gradient, shapes, editable text with outline and shadow, live blur, image export) plus the History panel that proves it. Recorded on the live site if the deploy has happened by then (the owner allowed a deploy on 2026-10-14), otherwise on the local build, and the card says which. Same pipeline as v6 (`film/README.md`, `build_v6.py`, the Kokoro fitter, `oplogpic_audio.py`); a new `film/record_v7.js` and `film/dialogue_v7.py` are written ONLY when the owner says go. Every spoken fact names its source; numbers that depend on the poster are read from a `facts.tsv` the recording script writes, never typed by hand.
