Selection discipline: pulled from Skalgubbar's own "sitting"/"standing"/"walking" tag
archives, downloaded, then verified as real alpha-channel cutouts (PIL histogram check
— not just trusting the filename) before inclusion; visually spot-checked every file
in this set before committing. Deliberately excluded from this pass: group/multi-person
shots, kids/pets, and heavy seasonal outerwear — kept to single-figure, season-neutral
poses so the starter set reads as generic building-occupant staffage rather than a
specific candid scene. Not yet wired into any rendering code — sourcing only, per
PHOTOREAL_STILL_RENDER.md §SPEC Part A open questions (placement/regeneration logic
still to be designed).
