QUALITY CONTROL — 2 of the original 8 candidates downloaded were REJECTED after
visual inspection: "maple tree with fruits" and "small city linden with fruits" both
had genuine RGBA alpha channels (would have passed an alpha-histogram-only check) but
the actual cutout was botched — original sky/ground background was still intact
inside the tree's silhouette, only the four image corners were transparent. Caught by
viewing every candidate at full resolution before vendoring, not by trusting the
alpha stats alone. Do not re-add those two without a manual crop/re-mask first.

PROCESSING: originals were 2100-3500px/6-9MB each (~46MB for 6) — too heavy for a
plain git blob at that size. Downscaled to a 1024px long edge (matches this
project's existing 1K-texture convention, e.g. Layer 3 PBR/Layer 2 HDRI) and
palette-quantized to 256 colors + alpha (PIL FASTOCTREE, Floyd-Steinberg dither) —
cuts total size ~30x (46MB -> 1.5MB) with no visible quality loss at normal preview
size; introduces mild dither speckle under close zoom, acceptable for a background
billboard viewed at distance, not verified acceptable for a close hero shot. If a
future use case needs a close-up tree, re-derive from the original download instead
of upscaling these.

Selection discipline: same as the people set — pulled from the site's tree tag
archive, downloaded, verified as genuine cutouts by viewing each one (not trusting
alpha-channel presence alone, per the QUALITY CONTROL note above), picked for
species/size variety, all full-leaf/season-neutral (no bare winter trees, to match
the people set's season-neutral discipline). Not yet wired into any rendering code —
sourcing only, per PHOTOREAL_STILL_RENDER.md §SPEC Part A open questions.
