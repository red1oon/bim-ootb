## 2. Witness W-LIBERO-ACTIVITY (`erp/tests/witness_libero_activity.js`), GardenWorld order 100 x Fertilizer, node "Packing Process" (resource 50006 = product 50024, UOM Hour; workflow unit seconds, batch size 200; node Queuing 0 / Waiting 1 / Moving 2; required qty 100, DurationRequired 3). FIXTURE (labelled): resource product 50024 costing Standard, Labor (element 105) price 12.00 and Burden (50000) 3.00 per hour, order QtyBatchs = 2.
Hand arithmetic for one Activity Control collector (qty 100, DurationReal 1800 s, SetupTimeReal 0):
- total duration = (0 + 1 + 2) x QtyBatchs 2 + 0 + 1800 = 1806 s; in hours 1806 x 1 / 3600 = 0.5016666666666667 (double).
- Labor 12.00 x 0.5016666666666667 = 6.0200000000000004 -> 6.0200; Burden 3.00 x ... = 1.5050000000000001 -> 1.5050; Overhead 0 (no Material, no Outside Processing detail). Details: amt -6.0200 / -1.5050, qty -0.5016666666666667, schema 101 (200000 has price 0).
- node: QtyDelivered 100 >= Required 100 -> Closed (CL); DateStart = movement date minus 1800 s; DateFinish = movement date; DurationReal 1800, DurationRequired becomes 1800; description "closed ( Duration :3) ( QtyRequired :100)".
- posting (schema 101): DR WIP -6.02 / CR Labor acct -6.02 and DR WIP -1.51 / CR Burden acct -1.51 (the Java passes the negative detail amount un-negated; GardenWorld allows negative posting; HALF_UP to currency precision 2).
- the order's finished-goods cost then includes the activity: `calculateFG` adds the FIRST cost detail of the activity collector (upstream behaviour) to remaining.
- Refusals: a second activity collector on the Closed node -> "Cannot change status from CL to IP"; on a Completed node -> "Order Activity Already Processed - MPPOrderNode[<id>-Packing Process]"; a milestone node -> DEFERRED text; nothing written.
Breaks (MUST exit 1): `LACT_BREAK=nobase` (duration not converted to the resource UOM), `noclose` (node not closed), `batchmult` (queue/wait/move not multiplied by QtyBatchs).
