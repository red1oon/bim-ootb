**not** buy go-to-definition: 1,684 plain `<script>` files, zero `import`/`export`, and the
god object is written `A.x` but read `APP.x`. No editor can follow that. The substitute is
`internal/APP_SURFACE.md` — 1,098 fields, each with its production definition as `file:line`,

## §C  TASK 2 — the guards to review other lanes against

These came out of a long session on 2026-09-12/14. Full reasoning is in `CodeScrapBook.md` and
its archive; this is the checklist.

**On evidence**
1. A `§`-tag proves code *ran*, never that the picture came out right. If a lane reports "every
   witness PASSes" while the user sees bugs on screen, the witnesses are checking the wrong
   thing — say so, and point at CodeScrapBook §14 (camera raycast / project / readPixels).
2. Never derive a finding from comparing frames. A pixel read at a coordinate computed *from the
   model* is evidence; a whole-frame diff is not.
3. Before believing a PASS, ask whether that test could have failed.

**On closure**
4. Fixing the instance is not closing the class. Ask: "what is the general form of this bug, and
   did you check for it?" This is the single most common failure, mine included.
5. "I changed the code" is not "the behaviour changed". Ask for the log line.

**On scope**
6. Stop the inflow before clearing a backlog. 144 of 345 duplicate harness copies were added
   *after* the shared version existed — converting the old ones while the rate continues is
   unbounded work.
7. Never sweep. Per module, per file, verified each time.
8. A guard people route around is worse than none. If a check has false-fired and been worked
   around, delete it rather than tune it.

**On the trees**
9. Two repos, different jobs: `bim-ootb` is the product, `bim-compiler` is the lab and the
   published papers. `deploy/dev` is **production** (it feeds the OCI bucket) — not a stale
   mirror, do not "clean" it. `build/erp` feeds `measure_bloat.js`; removing it silently changes
   a published number. Detail: `bim-compiler/prompts/LFS_QUOTA_AUDIT.md` §6.
10. Edit only in a `/tmp/wt-<feature>` worktree. The shared tree is hook-denied.

**On this file and others like it**
11. Consolidate on sight past ~1,200 lines; archive closed sections, keep the register whole.
12. Written guidance does not cross session boundaries. Only a file that gets *executed* does —
    a witness, a script, a hook. If something must survive, make it exit non-zero.
